# 🔮 SPOTLINE: 삼겹살집 내일 방문객 수 예측 통계 모델

> 📁 **순수 소스코드 즉시 검토**: 주피터 노트북 렌더링이 불안정할 때는 단일 파이썬 스크립트인 [**`spotline_model.py`**](./spotline_model.py)를 열어 소스코드를 즉시 조회하고 로컬에서 바로 실행해 보실 수 있습니다.

## 💡 1. 릿지 회귀(Ridge Regression) 선택 이유

| 핵심 판단 요인 | OLS (일반 선형회귀) / 복잡한 ML 모델 | 릿지 회귀 (Ridge Regression) |
| :--- | :--- | :--- |
| **과적합(Overfitting) 방지** | 30일치 초소형 데이터셋에서 노이즈까지 다 암기하여 일반화 성능 처참 | **L2 가중치 규제**를 적용해 가중치가 비대해지는 것을 억제하고 견고한 예측력 유지 |
| **학습 안정성** | 비선형 모델은 최적화 루프 중 Local Minimum에 갇히거나 무한 루프 위험 존재 | 수학적 **닫힌 공식(Closed-Form)**으로 단 1회의 행렬 연산으로 안정적 최적값 수렴 |
| **현업 설명 가능성** | 딥러닝/앙상블 모델 등은 블랙박스 구조라 각 변수의 영향도 파악 불가 | 기온, 요일, 날씨의 영향도를 **회귀 계수(Coefficients)**로 완벽히 정량화하여 제공 |

## 🛠️ 2. 피처 엔지니어링 및 미래 피처 제거 (Data Leakage 차단)

> [!IMPORTANT]
> **데이터 누수 (Data Leakage) 경고**
> '내일 방문자 수' 예측은 **오늘 밤 영업이 끝난 시점**에 수행합니다. 내일 밤 영업이 끝나야 수집되는 미래 정보(체류시간, 이탈 손님 등)를 예측 모델의 피처로 넣으면 실전 배포 시 입력해 줄 데이터가 없어 모델이 작동하지 않습니다.

### 📊 피처 전처리 및 선별 요약

| 분류 | 대상 피처 | 처리 방식 및 근거 |
| :--- | :--- | :--- |
| **🚫 제거 (미래 데이터)** | `avg_dwell_time`, `just_left_count`, `max_empty_table_time`, `max_response_wait_time`, `peak_time`, `people` 정보 등 | 예측 시점(오늘 밤) 기준 아직 발생하지 않은 미래 정보이므로 **완전 배제** |
| **🛠️ 가공 (신규 생성)** | `is_weekend` | `captured_at`에서 요일을 추출하여 주말(토,일)은 `1`, 평일은 `0` 매핑 (주말 ~65명, 평일 ~40명 분포 반영) |
| **🛠️ 가공 (Lag 피처)** | `prev_day_count` | **오늘(내일 기준 어제)**의 최종 방문자 수. 최근 방문 추세를 반영하는 시계열 지연(Lag) 정보 |
| **☀️ 활용 (예보 데이터)** | `temperature`, `weather` | 내일 날짜 기준의 기상 예보 데이터를 그대로 가져와 입력값으로 사용 |

## 📈 3. 통계 모델 성능 및 피처 영향도 분석

릿지 회귀 모델을 학습(Train 23일, Test 6일)한 실제 성능 검증 및 수치 요약 보고서입니다.

### ① 모델 예측 성능 지표
* **평균 절대 오차 (MAE)**: **5.87 명** (하루 평균 50명 방문 기준 약 11% 이내의 오차 수준으로 매우 정교하게 예측)
* **결정계수 (R² Score)**: **0.6841** (전체 방문객 변동성의 약 68.4%를 설명해 냄)

### ② 피처별 영향도 (회귀 가중치)

| 입력 피처 | 영향도 가중치 | 💡 비즈니스 관점의 해석 |
| :--- | :---: | :--- |
| **`is_weekend` (주말 여부)** | **`+8.3198`** | 삼겹살집 방문의 가장 절대적인 요인. 주말(토/일)에는 평일보다 **약 8.3명**이 더 방문함. |
| **`weather_RAINY` (비 예보)** | **`+1.3463`** | 비가 오는 날씨는 삼겹살에 소주를 찾는 식문화가 반영되어 방문 고객이 **약 1.35명** 더 증가함. |
| **`temperature` (기온)** | **`+0.8715`** | 기온이 오를수록 외출 확률이 소폭 증가해 유입 인원이 아주 미세하게 증가함. |
| **`weather_SUNNY` (맑음 예보)** | **`-0.1949`** | 날씨가 맑은 예보는 삼겹살집 유입에 거의 영향이 없거나 미세하게 감소함. |
| **`prev_day_count` (어제 방문객)** | **`-0.7832`** | 어제 손님이 비정상적으로 붐볐다면 오늘은 약간 쉬어가는 단기 외식 소비 주기를 보임. |

## 🔮 4. 실시간 내일 방문객 수 예측 시뮬레이션

### 💻 추론 모듈 구동 예시
* **시나리오**: 내일 최고 기온 `21.5 ℃`, 날씨 예보 `RAINY`(비), 오늘 최종 마감 정산 고객 `42 명`
* **모델 예측 연산 결과**:

```text
[시뮬레이션 1. 비 내리는 평일]
🔮 [SPOTLINE AI 내일 예측 보고서]
  - 예측 기준 일자: 2026-06-01 (월요일)
  - 내일 최고 기온: 21.5 ℃
  - 내일 기상 상태: RAINY
  - 오늘 최종 방문자수: 42 명
--------------------------------------------------
👉 내일 삼겹살집 예상 방문객 수: 【 46 명 】
```
